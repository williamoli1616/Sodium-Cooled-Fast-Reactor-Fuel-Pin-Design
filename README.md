This repository contains the summary and supporting materials for the design of a sodium-cooled fast reactor fuel pin, developed as part of the Nuclear Design course at Politecnico di Milano. It includes:

A complete Python implementation of the design calculations

The final report in PDF format, detailing assumptions, results, and verification

The design requirements document provided by the course instructors

The design process includes a comprehensive characterization of both the thermal and mechanical behavior of the fuel pin.
